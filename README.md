# Как не потерять аккаунт Claude / Codex — учебная страница

Статическая страница (`index.html`, без сборки и внешних зависимостей), четыре части: (I) аккаунт, копии, «умная папка», план первых суток; (II) защита проектов от взломов и применение в жизни; (III) основы GitHub для работы с Claude Code; (IV) 11 репозиториев октября с инструкциями по установке. Чек-лист и квиз. Оформление — в духе Sigma Design System.

Инструкции по обходу региональных ограничений сознательно не включены.

Цифры, цены и правила меняются — сверяйтесь с официальными страницами сервисов.
