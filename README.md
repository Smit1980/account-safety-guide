# Как не потерять аккаунт Claude / Codex — учебная страница

Статическая страница (`index.html`, без сборки и внешних зависимостей): цифры блокировок, правила, причины банов, ежедневные привычки, копии и экспорт, «умная папка» с контекстом, план первых суток после блокировки, работа по API-ключу, особенности Codex, чек-лист и квиз.

Основано на гайде «Claude и Codex без бана» (Эдвард Гришин, Futura AI) и приложенной папке «моя-база». Инструкции по обходу региональных ограничений сознательно не включены.

Цифры, цены и правила меняются — сверяйтесь с официальными страницами сервисов.
